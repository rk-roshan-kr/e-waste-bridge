# No Emojis Rule

## Mandate
Strictly prohibit the use of emojis anywhere in the codebase.

1. **Source Code**: Never insert pictorial emojis in JavaScript, JSX, CSS, HTML, JSON, or any other source code files.
2. **Comments and Docstrings**: Use plain text, standard ASCII labels (such as `[PASS]`, `[FAIL]`, `[INFO]`, `->`), and clear technical descriptions. Never use emojis in code comments.
3. **Strings and UI Text**: All user-facing strings, buttons, chips, logs, and notification messages must use clean typography, text labels, or SVG/Lucide icons, never inline emoji characters.
4. **Test Files and Scripts**: Use `[PASS]`, `[FAIL]`, or plain text in console logs and assertions.
5. **Responses and Commit Messages**: Avoid emojis in commit messages, technical documentation, and assistant responses.
